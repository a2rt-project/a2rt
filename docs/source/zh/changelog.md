# 版本与草案状态

## 0.2 草案 · 2026-11-15

线协议标识：`a2rt/0.2`。

- 各轨道独立更新，环境可主动交付反馈，assistant 可独立发送 `media`。
- 移除 0.1 的 `after_reply` 决策许可；`round_id` 改为 `output_seq`。
- `reply_to` 仅表达请求关联，同一 output 可得到多次进展反馈。
- Profile 声明具名执行策略，每个 context 选择并冻结 `execution_policy_id`。
- 分别限制活动操作数和未获得首条回执的事件数。
- 提供计数器环境的异步与流式示例、JSON Schema 和文档校验器。

这是不兼容的草案修订。不能把旧录制只替换版本号后当作 0.2 使用。

## 仍需工程验收

生产适配器、具体传输绑定、媒体资源与完整性验证、跨服务幂等、真实时钟映射、丢包恢复、同步依赖环检测，以及模型对观察信息的实际利用。

网站中的交互时间线是说明性图示，不是运行时、性能基准或兼容性认证。
