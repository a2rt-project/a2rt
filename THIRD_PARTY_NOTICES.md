# Documentation theme provenance

The Sphinx documentation theme under `docs/theme/psdocs`, the documentation
configuration scaffold, and `scripts/build_index.py` are adapted from
[ProteinSeek Workbench Docs](https://github.com/proteinseek/proteinseek-workbench-docs),
commit `27e632de8ada413b8255921535e839a2bb16c0bc`.

The imported snapshot contains the presentation and indexing code only. Upstream
Git history, credentials, deployment targets, Docker configuration, and product
documentation are not imported. The upstream snapshot did not include a LICENSE
file; attribution here does not grant additional rights to that code.

The A2RT 0.2 draft, schemas, fixtures, and validator in `protocol/` originate from
the local `naoix-web-chat/docs/design/a2rt` specification dated 2026-11-15.
Website content describes that draft; it does not claim a production SDK or
transport implementation.
